# 蓝心 API RAG 与离线 RAG 对比结论

## 测试条件

- 输入：`Transformer介绍.docx`
- 共同能力：Week03 结构化分块、HybridRetriever、Citation Grounding
- 离线生成：Week03 deterministic grounded builder
- 在线生成：蓝心/vivo API Provider
- 当前在线模型配置：`Doubao-Seed-2.0-mini`
- 在线调用采用严格模式，`fallbackUsed=false`

当前配置通过蓝心/vivo API 接入，但实际模型名为 `Doubao-Seed-2.0-mini`。如果比赛要求必须使用 BlueLM 原生模型，需要将 `LANXIN_MODEL` 改为平台实际提供的 BlueLM 模型名后重新测试。

| 指标 | 离线 RAG | 蓝心 RAG |

| 回归启发式质量分 | 0.9126 | 0.8763 |

## 稳定性观察

- 蓝心首次完整对比生成 4 条笔记、耗时 45,584 ms；第二次生成 15 条笔记、耗时 40,206 ms。
- 蓝心内容数量存在明显波动，即使调用参数保持一致。
- 在线接口曾出现一次 60 秒读取超时；增加 90 秒超时和一次重试后，真实集成测试通过。
- 两次蓝心结果的契约、来源链接和引用原文命中率均为 100%，说明 Week03 Citation Grounding 能稳定约束模型输出。

## 结论与部署建议

1. 保留 Week03 Citation Grounding 作为权威引用层，不能直接信任模型生成的引用。
2. 蓝心适合生成摘要、学习笔记和复习题；离线 RAG 适合作为低延迟兜底和稳定基线。
3. 生产默认使用蓝心生成加 Week03 引用绑定；当蓝心超时或质量门禁失败时切换离线 RAG。
4. 在 Prompt 中固定笔记数量和输出粒度，并将温度进一步降低，减少在线结果波动。
5. 上线前增加缓存、超时、重试、并发限制与每日回归对比。

机器可读结果与完整输出位于 `backend/evaluation_outputs/lanxin_vs_offline/`。
