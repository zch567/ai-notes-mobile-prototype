# AI 笔记移动端原型

这是一个基于 React + Vite + Tailwind CSS 的移动端前端原型，用来展示一个 AI 驱动的笔记产品界面。

## 功能

- 首页：AI 入口、推荐内容、基础导航
- 笔记页：搜索、分类、笔记卡片
- AI 页：链接、文档、文本输入生成笔记
- 处理中页面：模拟 AI 生成状态
- 结果页：摘要、结构化笔记、关键点
- 思维导图页：简化的知识结构展示
- 个人中心：账号与偏好设置

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 技术栈

- React
- Vite
- Tailwind CSS
